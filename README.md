# Solar System Explorer

An interactive website showcasing our Solar System with animated planets orbiting the Sun.

## Features

- Animated planetary orbits
- Interactive planets with hover effects
- Detailed information panel for each celestial body
- Responsive design
- Starry background with twinkling effect

## Usage

Simply open `index.html` in a web browser to explore the Solar System.

Click on any planet or the Sun to view detailed information about it.

## Technologies

- HTML5
- CSS3 (animations, gradients, transforms)
- Vanilla JavaScript
